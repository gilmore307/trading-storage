# shared

Trading-wide reusable static files live here when they are not templates.

Use this folder for reviewed cross-project files such as shared vocabularies, lookup tables, examples, or other static assets that multiple repositories may reference. Do not store secrets, generated runtime outputs, caches, or component-owned implementation files here.

Current files:

- `layer_01_02_market_context_etf_universe.csv` — curated ETF universe for market-state and U.S. sector/industry/theme observation. `model_layer` is the authoritative Layer 1 / Layer 2 scope discriminator: `layer_01_market_regime` rows feed Layer 1 market-context construction, while `layer_02_sector_context` rows feed Layer 2 sector/industry/theme observation and holdings analysis. `feature_grain` is the intended downstream observation/feature grain; source acquisition downloads canonical 1-minute bars.
- `layer_01_02_market_context_relative_strength_combinations.csv` — curated market-context relative-strength combinations. `model_layer` is the authoritative scope discriminator: `layer_01_market_regime` rows feed Layer 1 broad market/cross-asset evidence; `layer_02_sector_context` rows feed Layer 2 sector-context evidence. Each row defines `numerator_symbol / denominator_symbol`, `combination_type`, feature-grain cues, `feature_bar_grain`, and `interpretation`. Generated feature values do not belong here. Its columns are registered in `trading-manager`.

- `layer_02_target_context_mapping.csv` — reviewed target-to-Layer-2-context and auxiliary proxy mapping. Layer 3+ target-specific studies may use this file to map non-equity targets such as `BTC`, `ETH`, or `SOL` back to Layer 2 context (`BKCH`) while keeping single-asset ETF proxies (`IBIT`, `ETHA`, `FSOL`) out of Layer 1/2 market/sector context. It may also map equity targets outside a direct holdings-derived context into reviewed Layer 2 business/theme context rows, such as `AAOI` to `AIQ`, `XLK`, `SMH`, and weak downstream `XLC`. Proxy symbols in this file are target-specific auxiliary evidence references; they do not become market-regime or sector-context universe rows. This file is seed/fallback mapping evidence for ordinary targets; the accepted future weighting standard is dynamic `target_context_profile` evidence from correlation, lead-lag, influence direction, and confidence.
- `equity_total_symbol_pool.csv` — reviewed optionable equity total-symbol pool used by calendar and event-source monitoring. It is built from local reviewed input artifacts such as manually exported TradingView screener CSVs, Layer 2 ETF holdings CSVs, and optionable-underlying lists. It must not depend on unattended TradingView browser/API collection.
- `equity_total_symbol_pool.symbols.txt` — machine-readable symbol list derived from `equity_total_symbol_pool.csv` for `trading-data-calendar-maintenance.service`.
